# Student Performance Analyzer

A beginner-friendly Java project that analyzes a student's performance based on their marks in Mathematics, Physics, and Chemistry.

I made this project while practicing Java fundamentals and gradually added different features to understand how conditions, variables, methods, and user input work together in a complete program.

## What This Program Does

The program takes the following information from the user:

- Student name
- Mathematics marks
- Physics marks
- Chemistry marks

It then calculates:

- Total marks
- Overall percentage
- Grade
- Strongest subject
- Weakest subject
- Overall performance level

## Features

### 1. Total Marks
The program adds the marks of all three subjects to calculate the total score.

### 2. Percentage
It calculates the student's percentage based on the total marks out of 300.

### 3. Grade
The program uses 'if', 'else if', and 'else' statements to assign a grade according to the percentage.

### 4. Strongest Subject
The marks of Mathematics, Physics, and Chemistry are compared to find the subject in which the student performed the best.

### 5. Weakest Subject
The program also compares the subjects to identify the subject with the lowest marks.

### 6. Performance Level
Based on the percentage, the program displays a simple performance level such as:

- Needs Hardwork
- Good
- Excellent
- Superb

## Example

For example, if a student gets:

- Mathematics: 81
- Physics: 44
- Chemistry: 98

The program calculates the total marks and percentage and identifies Chemistry as the strongest subject.
